    What happens when you click a short link

    1. Rate limiter: a Lua script in Redis counts requests per IP per window, atomically.
    2. Cache lookup: Redis is checked first; only on a miss does the server query Postgres, then it caches the result with a TTL.
    3. 302 redirect is sent right away. A 302, not a 301, so browsers don't cache it and every click is counted.
    4. Analytics job is pushed to a BullMQ queue; a worker writes the click to Postgres in a transaction, off the redirect path.
    5. If Redis goes down, redirects fall back to Postgres; creating links pauses (fail-closed) so the rate limit can't be bypassed.
    Hosted on a free tier: the first request after a quiet period can take ~30–60 s while the server wakes up.
